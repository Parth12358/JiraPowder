JiraPowder Source on GitHub

See what blocks your Jira tickets.

JiraPowder is a Mac app that draws your sprint as a map of blocking links, so you can see what to start now and what is waiting. It only reads from Jira, through the same mcp-atlassian server you use with Claude.

Download for Mac For Apple Silicon and Intel Macs, macOS 12 or later

Install and set up JiraPowder for me on this Mac.

JiraPowder is a read-only macOS app (github.com/Parth12358/JiraPowder) that maps which Jira tickets block which. It reads Jira by starting the mcp-atlassian MCP server itself.

1. Install the app
   - Get the latest release from https://api.github.com/repos/Parth12358/JiraPowder/releases/latest and download the asset whose name ends in "_universal.dmg".
   - Mount it with `hdiutil attach -nobrowse`, copy JiraPowder.app to /Applications (replace an older copy if there is one), then detach the image.
   - Run: xattr -dr com.apple.quarantine /Applications/JiraPowder.app
- If ~/Library/Application Support/dev.parth.jirapowder/config.json already exists, JiraPowder is already set up: skip to step 6 (settings, token, colours and notes are kept). If an old Blockmap.app is in /Applications, ask me before deleting it.

2. Find my Jira MCP server settings
   - Check `claude mcp list` (and `claude mcp get <name>`), then ~/Library/Application Support/Claude/claude_desktop_config.json under "mcpServers".
   - Use the server that runs mcp-atlassian. I need its command, args, JIRA_URL, JIRA_USERNAME and JIRA_API_TOKEN.
   - If I only use Atlassian's hosted server (mcp-remote or mcp.atlassian.com), stop and tell me: JiraPowder does not support it yet.
   - If you find nothing, ask me for my Jira site URL, my Atlassian email, and an API token from https://id.atlassian.com/manage-profile/security/api-tokens
   - Make sure the command works (for uvx: `uvx --version`; if it is missing, `brew install uv`).

3. Ask me which Jira project key to show (for example PAY) unless it is obvious.

4. Save the API token in the macOS Keychain, not in a file:
   security add-generic-password -U -s jirapowder -a jira_api_token -w '<token>'
   Never show the token in your replies.

5. Write ~/Library/Application Support/dev.parth.jirapowder/config.json (create the folder; if the file exists, show me what you will change first):
   {
     "version": 1,
     "profile": "mcp-atlassian",
     "server": {
       "command": "uvx",
       "args": ["mcp-atlassian"],
       "env": {
         "JIRA_URL": "https://<site>.atlassian.net",
         "JIRA_USERNAME": "<email>",
         "JIRA_API_TOKEN": "keychain:jira_api_token"
       }
     },
     "site": "https://<site>.atlassian.net",
     "projectKey": "<KEY>"
   }
   Use the command and args from my existing server config if they differ (for example a full path to uvx, or a pinned version). Copy any other env vars it has, except tokens.

6. Open it with `open -a JiraPowder`, then tell me what to expect: macOS may ask whether JiraPowder can use the "jirapowder" Keychain item (choose Always Allow), and the map loads my open sprint. ⌘R refreshes.

Do not change my Claude configuration or anything in Jira.

Claude Code asks before it runs each command, so you can watch every step. If you don't have Claude Code, the install guide takes a minute, or use the steps under Myself.

  1. Install the app

    Download the .dmg above, open it, and drag JiraPowder to Applications. The app isn't notarized by Apple, so the first time, right-click it and choose Open. If macOS says it is damaged, run:

    xattr -dr com.apple.quarantine /Applications/JiraPowder.app

  2. Install uv

    JiraPowder starts mcp-atlassian with uvx. Skip this if uvx --version already works.

    brew install uv

  3. Create a Jira API token

    Make one at id.atlassian.com → Security → API tokens, or reuse the one in your Claude MCP config.

  4. Connect Jira

    Open JiraPowder. Settings opens on the first launch (later: ⌘,). Fill it in like this:

    Profile
    mcp-atlassian
    Command
    uvx
    Arguments
    mcp-atlassian
    JIRA_URL
    https://yourcompany.atlassian.net
    JIRA_USERNAME
    you@yourcompany.com
    JIRA_API_TOKEN
    your token with Keychain ticked
    Site URL
    https://yourcompany.atlassian.net
    Project key
    PAY (yours)

    Press Save. JiraPowder tests the connection and loads your open sprint.

Only reads

JiraPowder can call three tools: search, get issue and list fields. Anything that could change Jira is refused inside the app, and mcp-atlassian always runs with READ_ONLY_MODE=true. Your token stays in the macOS Keychain.

If something is off

  • Couldn't find uvx: install uv (step 2), or put the full path from which uvx in Command.
  • No story points: Settings → Detect finds your site's field.
  • Anything else: Settings → Diagnostics shows the server log. Open an issue with it; secrets are masked.

Updating

Download the new .dmg and drag JiraPowder to Applications, replacing the old copy. Your settings, token, cached tickets, colours and notes are kept. If the Dock still shows the old icon, run killall Dock. Still have Blockmap.app, the name before v0.1.2? Delete it and set JiraPowder up once.

Big sprints and colours

Each card's outline shows whose ticket it is, and the stripe on its left shows whether it is blocked, ready, in progress or done. Pick your own colours in Settings → Colours. With hundreds of tickets, Fit zooms out to show them all as coloured blocks; zoom in for the full cards. JiraPowder loads up to 500 tickets by default; change it in Settings → Jira → Ticket limit. To mark tickets for yourself, pick a colour tag or add comments in the ticket details. They stay on your Mac and are never sent to Jira.
